# MHT-CET Physics dataset with figures v1.3.0

This is the upload-ready strict-CET Physics dataset.

- Question records: 3,045
- Questions with figures: 20
- Unique high-resolution figure assets: 17
- Figure format: monochrome PNG, 1800 x 1200 pixels, 300 dpi
- Canonical bank: `question_bank_physics_with_figures_v1.3.0.json`
- Asset manifest: `asset_manifest_v1.3.0.json`

For every question with a non-null `figure_asset`, resolve the path relative to the root of this dataset and display the image above the answer options. Alt text is stored in the asset manifest. Questions without an asset retain `figure_asset: null`.

The figures are original, precise technical line art created for this bank. They do not reproduce a copyrighted examination image.
