# MHT-CET Chemistry Full Dataset v2.0.0

Deployable full-subject Chemistry bank for the MHT-CET 2026 scope.

- 3,040 single-correct MCQs across 10 Standard XI and 16 Standard XII chapters
- XI/XII counts: 640 / 2,400
- Difficulty: Easy 768, Medium 1,220, Hard 752, Challenging 300
- Correct options: A/B/C/D = 760 each
- 23 necessary exam-style SVG figures with an asset manifest
- 244 quantitative questions with stored calculation checks (216 newly parameterized plus retained repaired numericals)
- JSON Schema, per-chapter JSON, generator blueprint, sample 50-question paper, validation report and master workbook

The 40 repaired Chapter 1 questions are preserved. No approval or human-review status fields are present. Difficulty is editorial, not psychometrically calibrated.
