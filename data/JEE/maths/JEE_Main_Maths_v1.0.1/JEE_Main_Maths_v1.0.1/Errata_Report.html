1. What was done

  1. Independent recomputation of every item. Fresh verifier agents received only the stem and the four options of each released question, in packs of about 50, with no keys, drafts or checking code. For each question they wrote and ran their own sympy or brute-force code (2,679 of 2,700 by code; the rest are conceptual and were reasoned), evaluated all four options, and reported every option equal to their result. They agreed with 2,699 keys. The single disagreement (JEE-MATH-U10-140) was a verifier error, confirmed by the editor with sympy. All 342 integer answers agreed.
  2. Hostile unit audit. Separate auditor agents read every full record (stem, options, key, explanation, distractor rationales, metadata) unit by unit and compared every pair within each slice. Categories: wrong key, ambiguity, explanation errors, integer alternates, distractor defects, duplicates and answer leaks, metadata, scope, presentation.
  3. Fixes. Correcting agents re-verified each finding with sympy before acting. Rules: a critical finding leaves exactly one defensible option; a duplicate that reuses the same data or answer is rewritten, a merely related item is linked by an alias dependency so the paper generator never pairs the two; class labels follow NCERT placement; quotas and IDs never change. Every batch was re-run through the authoring harness (machine check, KaTeX render, house style) with 0 blocking results.
  4. Bank-wide edits. Natural logarithms are now written log_e everywhere (87 items changed in notation only). 36 items moved to Class XI. 110 alias groups were added. Two integer alternates left the Section B pool (one now has a negative answer, one item lost its alternate in a rewrite) and were replaced like for like.
  5. Re-verification. All 132 items whose stem, options or integer alternate changed were rebuilt and sent to fresh verifiers. That pass flagged the phrase "(possibly equal)" in two Unit 2 stems as ambiguous; the editor reworded those and a third stem using the same phrase, and all three were verified again. A post-fix similarity scan of every rewritten item against the whole bank was reviewed by a separate agent: 57 pairs independent, 1 linked by a new alias.
  6. Automated test suite. 25 tests run against the finished release folder (section 6).

3. Critical findings

Two items were upgraded to critical because a second option could be defended. Both are fixed and re-verified. A third critical finding came from the re-verification pass.

ERR-054 · U03-C-044 (JEE-MATH-U03-154) · Ambiguous or under-specified stem

The stem adds 'non-symmetric' to rule out coincidences among the options, but that does not rule them out. For a non-symmetric orthogonal P (which is non-singular and satisfies PP^T = P^TP), options A (Q^2), B (I) and D (PP^T) all equal QQ^T. B is the only option that holds for every admissible P, but 'Then QQ^T equals' does not say 'for every such P', so a student can defend A or D.

Closure (fixed): Confirmed with sympy: for P = [[0,1,0],[-1,0,0],[0,0,1]] (non-symmetric, orthogonal, normal) Q^2 = PP^T = QQ^T = I. Stem now says 'real' and 'for every such P, QQ^T necessarily equals'; distractors PP^T and Q^2 replaced by -I and Q^T. Options now I, -I, Q, Q^T: Q = I iff P symmetric (excluded), so Q != I and Q^T = Q^{-1} != I; QQ^T has non-negative diagonal so never -I. Exactly one option holds for every admissible P. Rationales, values and explanation updated.

ERR-079 · U05-B-030 (JEE-MATH-U05-077) · Ambiguous or under-specified stem

Stem says 'For a positive integer n'; at n = 1 distractor C ($2n$) also equals the true ratio $2$, so C is a correct value for one admissible n.

Closure (fixed): Confirmed with sympy: at n = 1 distractor 2n equals the key 2. Stem now reads 'For every positive integer n'; distractor 2n replaced by (2n+1)/(n+1) (indices one more than given, mirroring the existing one-less slip (2n-1)/n). sympy: no option equals 2 and no two options coincide for any positive integer n; check extended to n = 1..10; rationales now show the computation.

ERR-300 · U02-C-042 (JEE-MATH-U02-152) · Ambiguous or under-specified stem
