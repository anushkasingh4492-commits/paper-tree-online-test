# NEET 2027 Chemistry Question Dataset with Figures — v1.1.0

Corrected bank for the 2025–2027 student cohort targeting NEET-UG 2027. It contains 2,160 four-option single-correct MCQs using +4/−1/0 marking, equal Easy/Medium/Difficult counts, independently shuffled answer positions, canonical schema fields, source-chapter mapping and original SVG chemistry figures.

The current official academic basis is the NMC/NTA NEET-UG 2026 Chemistry syllabus for academic session 2026–27. The official NEET-UG 2027 notification must be compared when published; only formally published deltas should be applied.

Primary imports: `neet_2027_chemistry_full_dataset.json`, `.jsonl` and `.csv`. Student delivery can use `questions_only.json`; scoring and review can use `answers_and_explanations.json`. Validation evidence is in `errata_report.json`, `errata_report.md` and `independent_validation.json`.
