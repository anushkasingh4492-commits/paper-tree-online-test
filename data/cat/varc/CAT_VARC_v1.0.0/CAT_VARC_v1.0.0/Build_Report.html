CAT VARC v1.0.0: build report

Paper Tree Educational Studio · 18 October 2026

What was built

400 original passages and 2800 questions across 12 chapters; 2200 MCQ and 600 TITA; 840 / 1260 / 700 Easy / Medium / Difficult. Passages average 481 words.

How it was made

  1. 94 drafting batches written to a common spec: original prose only, no invented quotations or statistics attributed to real people, a written defence for every wrong option. Subjects claimed in a shared register so parallel batches could not collide.
  2. Para jumble, odd one out and sentence placement keys are computed by code from the author's original ordered paragraph, so a key can never be mis-transcribed.
  3. Machine harness on every file: counts, word counts, readability, option-length giveaways (the key may be the longest option in at most 40 percent of items), house style, and 8-word overlap against every other file.
  4. Blind round 1: two independent solvers per item. Both matched the key on 2797 of 2800.
  5. Hostile editorial audit of every file, informed by the solvers' notes: 5 critical, 94 major and 734 minor findings, all critical and major fixed.
  6. Blind round 2 on the 257 changed items: both new solvers matched the key on 257.
  7. Build: option letters balanced by code; subject alias groups computed across item types so related items never share a paper; 9/9 automated tests pass.

Adjudicated disagreements

  • R05-B-04-2 (round 1, S2 answered differently): S2's own working argued for the keyed option; the typed letter was a slip. The keyed option was reworded to match the passage's 'came alongside' more exactly; round 2 both solvers agreed.
  • V01-A-006 (round 1, S1 answered 52314 against key 53214): S1's working supported the key; the typed order was a slip. Key retained.
  • V01-F-023 (round 1, both solvers answered 14325 against key 14352): the last two sentences could swap. The conclusion was rewritten so it can only follow the 'shields it' sentence; round 2 both solvers reached the key.

Limits

  • No human subject expert has reviewed the bank yet; human_subject_expert_reviewed is false on every record.
  • Difficulty labels are editorial judgements on the CAT scale, not yet calibrated with student data.
  • The web originality check was a 60-sentence spot check; the main protection is that every passage was written fresh.
  • Next phase: DILR (sets with code-drawn charts), on the same pipeline.
